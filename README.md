# Urban Routes Testing Project

## Project Description

Urban Routes is a TripleTen project focused on testing a web application.  
The main goal of this project was to perform regression testing and interface testing to verify that the application worked correctly and that the user interface behaved as expected.

## Project Objective

The objective of this project was to design, execute, and document tests for the Urban Routes website, focusing on regression testing, boundary values, interface behavior, and functionality.

## My QA Work

During this project, I performed the following activities:

- Designed test cases before executing the tests.
- Executed regression tests on the Urban Routes web application.
- Tested the interface and main functionality of the website.
- Identified bugs and inconsistencies related to interface and functionality.
- Created bug reports in Jira.
- Used DevTools to inspect and validate elements during testing.
- Documented evidence using screenshots.

## Types of Testing Performed

- Regression testing
- Boundary value testing
- Interface testing
- Functional testing

## Tools Used

- Excel
